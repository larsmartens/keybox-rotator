# Changelog

All notable changes to this project are documented here.

## [1.0.1] - 2026-07-25

### Added

- Initial public release of the fail-closed rotation service.
- Independent RSA and ECDSA private-key and certificate-chain validation.
- Live Google attestation-root and revocation-status checks.
- Permanent privilege drop to the Termux UID before validator HTTPS requests.
- Atomic replacement, timestamped backups, bounded logging, and manual action.
- KernelSU update metadata and a release ZIP build script.
