# Security policy

## Reporting a vulnerability

Use GitHub's private vulnerability-reporting form under the repository's
**Security** tab. Please include the affected version, expected behavior, and a
minimal reproduction.

Never attach a real `keybox.xml`, private key, backup, authentication token, or
other device secret. A structurally representative test fixture with newly
generated keys is sufficient.

## Supported versions

Security fixes are provided for the latest published release.
